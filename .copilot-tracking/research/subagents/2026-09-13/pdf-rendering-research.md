and --crash-dumps-dir under research. TEMP, TMP, TMPDIR, USERPROFILE, HOME,
LOCALAPPDATA, APPDATA, and XDG paths are redirected under each research run.
Normal browser profiles are not attached to or modified. No user browser
settings or registry values were changed. Background networking, component
updates, extensions, sync, crash reporting, and first-run behavior are disabled;

Both Chrome and Edge CDP startup emitted "DevTools remote debugging requires a

that an unknown default-directory result fails closed:
https://raw.githubusercontent.com/chromium/chromium/main/chrome/browser/devtools/remote_debugging_server.cc.
No security restrictions were disabled to work around that failure.

Built-in headless printing worked with the same confinement. PDF.js screenshot

did not finish its evidence script, including after three bounded verifier

## Limitations and parent handoff

* Use the exact render-only command above, without --verify. The retained optional
	verifier needs a separate authorized repair if fully automated PDF inspection
	is desired. The fixture itself has actual text/link and six-page visual evidence.
* Existing source anchors are generated from headings; unusual punctuation,
	Unicode, explicit raw-HTML IDs, or a heading literally named contents can need
	reconciliation. Missing links fail HTML preflight rather than silently passing.
* A pre-existing source contents section is not removed; the generated print TOC
	may duplicate it. A Contents heading can collide with the reserved contents ID.
	The primary was not read to determine whether this applies. Parent should check
	those two cases before final rendering and decide whether to adjust the helper.
* Frontmatter title extraction handles a simple scalar, not arbitrary YAML.
	Remote images are deliberately omitted; Mermaid is displayed as fenced code,
	not rendered as a graph. Ordinary ASCII diagrams are verified.
* Tables with many columns or a single row taller than a page, unusually wide
	mathematics, and extremely long lines still require final-source checking.
	Wrapping preserves source whitespace but does not add a hanging continuation
	indent; code copy/paste can contain print-created line breaks.
* HTML contains semantic MathML; PDF mathematics is visibly correct but complete
	screen-reader tagging and two-dimensional equation copy fidelity are unverified.
* Asset URL/hash manifest and license files must travel with the renderer. CSS
	contains alternate font URLs from upstream, but local WOFF2 fonts sufficed.
* Profiles and diagnostic files remain under research for evidence. They were
	not deleted, and no broader cleanup or environment change was attempted.
